# Self-Reports Do Not Identify Self-Models, project page

Project page for "Self-Reports Do Not Identify Self-Models: An Identifiability Test for Counterfactual Reports" by Phongsakon Mark Konrad, Toygar Tanyel and Serkan Ayvaz, an oral at the ICML 2026 Workshop on Philosophy of Machine Learning. The page is served at https://aiml-sdu.github.io/self-reports-page/.

This repository holds the built static page only. The plotted values come from the paper and its stored result files. The paper is on [arXiv](https://arxiv.org/abs/2609.32449) and [OpenReview](https://openreview.net/forum?id=iBq4yYwYfd). The code will be released separately.
